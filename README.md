## Intro :

Add variety to your Minecraft world with the *Dungeon Clusters* mod! This mod introduces **four unique dungeons** and the ability to find **clusters of dungeons**, making it perfect for creating large-scale **monster farms**.

### Features:

**Four Types of Dungeons**: Explore four distinct types of dungeons:
- **Zombie Dungeon**
- **Creeper Dungeon**
- **Skeleton Dungeon**
- **Spider Dungeon**

Dungeons are compact rooms made from **cobblestone** and **mossy cobblestone**, featuring a **mob spawner** and up to **2 chests** containing loot. Discover **clusters of dungeons** that can contain up to **27 spawners** in a single area. These clusters allow you to create massive **monster farms** for efficient mob farming and resource gathering.

### Summary:
- **Four Dungeon Types**: Zombie, Creeper, Skeleton, and Spider Dungeons.
- **Dungeon Clusters**: Up to **27 spawners** in a single cluster.
- **Loot Chests**: Each dungeon contains up to **2 chests** with loot.
- **Perfect for Monster Farming**: Use dungeon clusters to create **massive monster farms**.
