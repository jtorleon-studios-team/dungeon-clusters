## Intro :

Dungeon Clusters adds 4 new dungeon types to Minecraft, generated in clusters.
 
- **Zombie Dungeon**
- **Creeper Dungeon**
- **Skeleton Dungeon**
- **Spider Dungeon**

Dungeons are compact rooms made from **cobblestone** and **mossy cobblestone**, featuring a **mob spawner** and up to **2 chests** containing loot. Discover **clusters of dungeons** that can contain up to **27 spawners** in a single area. These clusters allow you to create massive **monster farms** for efficient mob farming and resource gathering.
